# Portable feature-preserving Mac delivery

The native window feature stays in the Next shell; ordinary DSH plugins do not replace it. `upgrade-cli.mjs` adds user-independent application/data discovery, complete package hash checking, app-only staging, adjacent backups, transaction receipts, rollback and interrupted-transaction recovery. No commands rewrite the user Profile, plugin membership, credentials, session history or window identity registry. Running target processes refuse installation/rollback; the operator closes the exact app normally.

`package` can export an already validated enhanced app or overlay hash-bound successful prepared source modules onto the exact matching official vendor version. Vendor native assets, unpacked ASAR policy, runtime architectures and hardened-runtime entitlements remain. Local ad-hoc signing is explicit. Source checks freeze runtime source, installer scripts and compiled modules; dependency drift and merge conflicts remain separate stops.

The delivery includes scripts and a user-relative launcher. Installed tools do not retain developer checkout paths; Node 22+ is preferred, with the already installed Electron Node as fallback. Code export/source merging requires the reviewed Git checkout and matching development dependencies. Recipients installing prepared packages need no source checkout.

Transactions preserve original application files and current data independently. Rollback does not undo settings edited after installation. It verifies both application trees and refuses unrelated later updates. Recovery recognizes only this tool's journal and dead lock owner; unknown/active locks remain. The updater deliberately does not kill running business tasks or promise compatibility with every future vendor data migration.

Tests use temporary directories, simulated process/copy faults and independent ASAR fixtures. Native Mac delivery/installation/rollback evidence is recorded by the calling task separately from these tests and from actual forward-port compatibility. Existing Windows behavior and plugin composition are outside this Mac installer.
